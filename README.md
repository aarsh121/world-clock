# World Clock

Scrub time across cities. Sticky desktop widget for Mac & Windows.

**Live:** https://world-clock-ivory-phi.vercel.app  
**Downloads:** https://github.com/aarsh121/world-clock/releases/latest

## Install

| Platform | File |
| --- | --- |
| Windows | `World.Clock_*_x64-setup.exe` |
| macOS Apple Silicon | `*.aarch64.dmg` |
| macOS Intel | `*.x64.dmg` |

## Develop

```bash
npm install
npm run dev
npm run tauri:dev    # needs Rust
npm run tauri:build
```
